# Blog Exemplars

| Source | Borrow |
|---|---|
| **Wenhao Chai** (wenhaochai.com/blogs) | Editorial white-paper layout, quiet left TOC, claim-first headings, zero-chrome two-accent figures with title and takeaway, a hero schematic right after the byline, very short declarative sentences, findings list. |
| **Lilian Weng** (lilianweng.github.io) | Survey structure, clear taxonomy, consistent notation table, every method placed in one map, generous citations. |
| **Distill / Chris Olah** (distill.pub, colah.github.io) | Explanation through figures, step-by-step intuition building, and reducing "Research Debt" by doing the reader's distillation work. |
| **Jay Alammar** (jalammar.github.io) | Schematic-first explanation before any equation, reusing one visual vocabulary across figures. |
| **Andrej Karpathy** (karpathy.github.io) | Starting from a concrete experiment or anecdote, conversational first person, showing raw samples or outputs. |
| **Anthropic / Transformer Circuits** | Interactive or annotated real examples as evidence and careful scoping of claims. |
| **Steven Pinker, *The Sense of Style*** | Classic style that shows the reader something concrete while avoiding metadiscourse and zombie nouns. |

When the user names a style reference, study 2 to 3 posts from it first (using the browser subagent when live pages are needed), and extract the opening move, heading style, paragraph length, figure frame, color use, number presentation, and closing move before drafting.
